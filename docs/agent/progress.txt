## Codebase Patterns
- Color variables (bold, gray, cyan, yellow, green, red) are defined as package-level vars in internal/cli/render/script.go and available across all files in the render package
- Success messages use green checkmark character (✓) with color.New(color.FgGreen), matching sync.go pattern — NOT emoji checkmark
- Fork integration tests all use SkipGolden: true, so no golden file updates needed for fork renderer changes
- The mise tool manager must be activated for Go tooling: `eval "$(/home/sol/.local/bin/mise activate bash)"`; also need `export PATH="$HOME/go/bin:$PATH"` for golangci-lint
- make fmt/lint don't work directly due to PATH issues — use the mise activation + explicit PATH setup instead
- To load raw (unexpanded) sender configs for display, use internal/config/display.go LoadRawSenders() — it re-parses the TOML without os.ExpandEnv
- For env var detection in config values, check for `${` prefix or `$` prefix — literal private keys start with `0x`
- Config command enrichment (adding data from RuntimeConfig) happens in the cobra handler showConfig() in internal/cli/config.go, not in the use case
