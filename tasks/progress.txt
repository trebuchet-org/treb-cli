## Codebase Patterns
- Auto-resolution logic lives in `ResolvedNamespaceToTrebConfig()` in `internal/config/trebfile_v2.go`
- The function converts V2 accounts to the flat `TrebConfig.Senders` map; any cross-reference resolution must happen here
- Transitive resolution uses recursive `resolveAccountChain()` with a visited slice for cycle detection
- `senderRefName()` helper extracts the referenced account name from Safe (signer) or OZGovernor (proposer)
- Role-name collisions (role name = account name but different config) are handled by comparing `senders[name]` with `accounts[name]`; if they differ, the explicit role mapping takes priority (FR-3)
- Tests for config resolution are in `internal/config/trebfile_v2_test.go` under `TestResolvedNamespaceToTrebConfig`
- Go toolchain is managed via mise; use `export PATH="/home/sol/.local/share/mise/installs/go/latest/bin:/home/sol/.local/share/mise/shims:$HOME/go/bin:$PATH"` before running go/lint commands
